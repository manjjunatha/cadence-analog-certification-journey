# Module 02 – Introduction to the Virtuoso Design Environment

## Objectives Covered

- Invoking the Virtuoso Design Environment
- Understanding configuration files:
  - .cdsinit
  - .cdsenv
  - .cds directory
- Using the Command Interpreter Window (CIW)
- Accessing setup forms via CIW
- Managing toolbars using Toolbar Manager
- Using Library Manager to:
  - Create libraries
  - Create cells
  - Copy and rename cellviews
- Exploring Schematics L and XL
- Understanding Schematic Migration feature

---

## Lab 2-1 – Getting Started

### Activities Performed

- Launched Virtuoso environment
- Explored CIW interface
- Checked working directory structure

### Key Learning

The CIW acts as the central control interface
for managing schematic design operations.
